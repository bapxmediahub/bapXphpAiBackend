# Engineering Guide

Runtime customer, admin, payment, wallet, consultation, and address data is remote MySQL data accessed through `DatabaseService`. Markdown and YAML are reserved for documentation, blog content, and media metadata; JSON fixtures are import-only.

Use `bapXphp map`, `bapXphp schema list`, `bapXphp check`, `bapXphp docsmap`, and `bapXphp smoke` as the standard verification chain.

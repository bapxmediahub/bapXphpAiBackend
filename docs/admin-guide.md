# Admin Guide

Use the dashboard to manage products, categories, coupons, orders, historical service records, temples, shipping, integrations, backups, audit logs, blog content, and the developer project map.

Public consultation booking is retired. Historical appointment records remain under Sessions, and Consultation Analytics summarizes those retained records.

# Current Objective

Maintain one clear product architecture:

- hosted MySQL for all admin-editable structured data;
- Markdown files with YAML frontmatter for blog articles;
- file storage for image binaries;
- generated indexes that point to original sources without copying runtime records;
- exactly two PHP application agents: customer support and owner/admin chat;
- no additional application agent or external agent runtime.

Work from verified open GitHub issues. Confirm every claim against current source and a
reproduction before implementing it. Keep `README.md`, `CLAUDE.md`, skills, maps, and
indexes aligned with the code that actually ships.

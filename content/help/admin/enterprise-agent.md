## Ask a focused question

Open Enterprise Agent → Chat. On Sri Panchami Spiritual the menu displays **Enterprise Agent Vinod**. Name the business fact and time period you need, such as paid sales for a specific date range or support-ticket counts. The agent uses named read-only tools and current permitted records. An unavailable query is different from a valid zero result.

Open **Help & Docs** for the owner guides. To get help in chat, ask about a specific task, such as how to prepare an unpublished blog post. Enterprise can read the matching guide and link to it from its answer. Use `/help blog-publishing` to ask directly about the blog-publishing guide.

Answers use readable sections and relevant cards. When a completed report tool provides figures, the answer shows labelled facts with the recorded source, date range and observation time. Missing figures remain unavailable. Use the source link to inspect the underlying report.

## Choose an owner task

Open **What can I ask?** above the conversation. It lists tasks your authenticated owner session can use. **Use this question** fills the composer so you can add a product name or change the period before sending. The examples below the composer also fill the message field.

| Task | Example question | What the answer means |
|---|---|---|
| Product performance | Show the product performance report for the last 30 days. | Units, recorded line value and allocated net line value, grouped by product name. |
| Current availability | Show the current stock status report. | Current product statuses and effective prices, including internal products; no stock quantities. |
| Customer patterns | Show customer order-frequency groups for the last 30 days. | Anonymous groups with one, two to four, or five or more paid orders in that period. |
| Coupon performance | Show coupon performance for the last 30 days. | Recorded uses, discounts and associated net order value, not proof a promotion caused the sales. |
| Individual order | Where is order followed by its exact order ID? | A scoped order lookup; include the exact identifier in your own question. |

Dated commerce reports cover at most 366 inclusive calendar days through today.
They return up to ten rows; summary values cover every matching record. The source
report link opens the full admin report. Stock is a current snapshot and does not
accept historical dates.

Paid-order amounts use recorded order dates and verified refunds on those orders.
They are not profit or settlement-date cash flow. Customer repeat counts describe
the selected period, not lifetime retention; orders with no valid customer key
remain separately identified in the aggregate count. Historical appointments can
be counted, but live availability, booking and rescheduling are not offered.

## Attach a reference

Use the paperclip to upload an image to Media and attach it to the message you are writing. For an existing image, page or article, type `@` and part of its name. Choose a suggestion with the arrow keys and Enter. Escape dismisses the list. Review the attachment names before sending.

## Continue or start fresh

The current chat reopens when you return in the same tab and owner session. Use **History** to pick an earlier conversation or **New chat** to start a separate thread. If a saved chat cannot be reopened or its last request is unfinished, use **Reload saved chat** to check for its saved reply. Report follow-ups can reuse the last successful single-scope report period. After comparing multiple report scopes, specify which period or report you mean instead of relying on an older period. Include explicit dates when you want a different period.

History keeps the figures recorded with that answer. Ask a new question to obtain current figures. If a card cannot be displayed, the complete saved answer remains readable as text.

## Review before acting

Inspect source links, filters and reported amounts against the corresponding business screen. Use /create-blog followed by your topic for a model-generated proposal. An empty /create-blog opens a manual form without inference. A failed provider request does not create a generated draft. Save unpublished draft uses the existing blog form; review and publish separately in Blog. A draft or suggestion is not a completed website edit. Review it and use the normal authorized form to save a change. Never put passwords, payment secrets or another customer's private data into a question.

If an answer is uncertain, use Agent Monitoring to inspect evidence. Do not repeat an uncertain ticket/action until its recorded outcome is checked.

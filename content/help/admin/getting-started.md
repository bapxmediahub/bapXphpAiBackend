## Start with the task

The sidebar groups daily work into Services, Commerce, Enterprise Agent, Email, Appearance and Settings. Select **Help & Docs** whenever you need instructions. **Help for this page** takes you to the guide for the section you are using.

Open Dashboard for an overview. Its 7, 30 or 90 day selector changes the paid-commerce period. An empty period is valid; a zero card is not a database failure. Use Commerce Reports for explicit from/to dates and deeper filters.

## Work safely

Reading a list or a guide does not save changes. Review each form, then use its explicit save or confirm action. Do not repeat payments, replies or deletions because a page is slow. Check the existing record first. Credentials and customer information belong only in the authorized workspace, not screenshots or public chat.

## Know the boundaries

The Enterprise Agent helps with read-only business questions and reviewed drafts. It is not permission to run arbitrary commands or change records automatically. Public consultation booking is retired; Sessions and Session analytics retain historical records rather than offering new appointments.

Guides explain available controls. If the interface and a guide disagree, record the section and safe reproduction details for the development team; do not guess a destructive workaround.

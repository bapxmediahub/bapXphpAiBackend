## Find the right account

Open **Users**. The registered-account counts cover the full directory. Select **No orders**, **One order** or **2+ orders** to narrow it by matched order count.

Use **Search accounts** for a name or email. Combine **Role**, **Order activity** and **Latest order**, then select **Apply filters**. The latest-order periods count calendar days in IST, including today. Use **Reset filters** to return to the default list.

Expand an account row to see its order history. Open an order by its reference or follow an issued invoice link. The list and order history show times in IST. Check identity carefully before discussing private information.

## Interpret matches correctly

Order activity is matched by checkout email. That match is useful context, not proof that two people or accounts should be merged. A customer without a matched order is still a registered account. Order counts include all matched order records. The filtered result count is shown separately from the registered-account counts.

## Keep access safe

This directory is not permission to impersonate a customer, reset a password without authorization or copy personal information to public chat. Refer account recovery to the supported sign-in/recovery workflow. Use the customer-facing account guide when explaining where orders, profile and saved addresses are found.

A role or contact change is a consequential operation. Use only an implemented authorized control and verify the result; do not infer that a readable field is editable.

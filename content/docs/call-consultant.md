# Call a consultant

## Request the call

1. Sign in and open **Consult**.
2. Select the phone icon on the consultant card.
3. Available consultants receive the request immediately. Offline or busy consultants receive a queued request.
4. Open the session from **Dashboard → My Sessions**.

The consultant must accept and start the session before the call button becomes active.

## Connect your microphone

Select **Start Call** and allow microphone access when your browser asks. Both participants should use a stable internet connection and headphones where possible.

Calls use the credit-per-second rate displayed before the request. A queued request does not consume credits. Billing begins only for an accepted call session.

## If audio does not connect

Confirm microphone permission, refresh the private session room, and try again. If the problem continues, end the session and contact support with the session ID shown in your dashboard.

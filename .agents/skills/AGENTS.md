# Skills DOX

## Purpose

Owns individual task skills for this PHP/JSON monorepo.

## Ownership

- Each `<skill-name>/SKILL.md` describes when and how to work in that domain.

## Local Contracts

- Keep skills concise and operational.
- Use root `AGENTS.md` plus the nearest child `AGENTS.md` as the authoritative contract.
- Do not point to deleted `.codex` or `.claude` skill folders.

## Work Guidance

- Update only the relevant skill when a durable workflow rule changes.

## Verification

- `php tests/run.php` when skill existence or wording is asserted.
